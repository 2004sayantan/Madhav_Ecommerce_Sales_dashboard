# Madhav_Ecommerce_Sales_dashboard

This project is an interactive Power BI dashboard created to analyze e-commerce sales data.

The dashboard provides useful insights into:

Total Sales Amount

Total Profit

Total Quantity Sold

Average Order Value

Sales by State

Sales by Customer

Sales by Month

Profit by Sub-Category

Sales by Product Category

Payment Mode Analysis


Users can also filter the data by State and Quarter to explore the sales performance in more detail.

This project helps in understanding business performance and identifying important sales trends using interactive data visualizations.

Tools Used: Power BI
